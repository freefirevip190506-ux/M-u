Shader Material Color Editor

Chỉnh màu X-Ray Color, Outline Color và độ dày viền (Outline Width) trong dữ liệu material nhị phân (hex dump), xem trước thay đổi, rồi xuất file .txt với hex code mới — mọi byte khác giữ nguyên.

Dữ liệu gốc

Công cụ dùng dữ liệu material nạp sẵn theo mặc định. Nếu cần chỉnh một material khác, nạp file .txt chứa hex dump của material đó.

Thay đổi so với gốc

Chỉ các byte thuộc 3 thuộc tính ở trên bị thay đổi khi xuất file — phần shader bytecode và mọi thuộc tính khác được giữ nguyên 100%.

    Xem hex code sau khi chỉnh (tùy chọn)
    Chỉ các byte của 2 màu RGBA và giá trị độ dày viền được thay đổi trong toàn bộ file — phần shader bytecode và mọi thuộc tính khác được giữ nguyên 100%.
